# 运行 MemoSphere

在仓库根目录执行 `mkdir -p .runtime`。本地体验可使用词法检索。

```sh
MEMOSPHERE_RETRIEVAL=lexical go run ./cmd/memosphere
```

访问 `http://127.0.0.1:18800/`。独立控制台默认将数据写入 `.runtime/app.sqlite3`。升级前先停止服务，备份数据库及同目录下的 SQLite WAL 文件，再在副本上验证。

## 邮箱登录

在权限为 600 的 `.runtime/smtp.json` 中配置自己的邮件服务。以下均为占位值。

```json
{
  "host": "smtp.example.org",
  "port": "587",
  "security": "starttls",
  "from": "memory@example.org",
  "user": "memory@example.org",
  "password": "YOUR_SMTP_PASSWORD"
}
```

## 自动整理与检索

手动记忆模式可直接启动。启用自动整理时，将兼容服务的模型设置放入权限为 600 的文件，通过 `MEMOSPHERE_MODEL_CONFIG` 指定路径。

```json
{
  "base_url": "https://api.deepseek.com",
  "model": "deepseek-flash",
  "api_key": "YOUR_PLATFORM_API_KEY",
  "thinking": "disabled"
}
```

若要使用本地 BGE 编码器，先运行 `uv sync --frozen` 和 `uv run --frozen python -m scripts.prepare_embeddings`，再按编码器环境设置启动默认的混合检索模式。宿主应用接入和项目授权见[客户端接入协议](客户端接入协议.md)。
