# 接入方验收样例

用两个测试客户端和一个测试项目检查记忆的整个生命周期。测试数据可使用虚构的住宿偏好。

| 操作 | 应观察到的结果 |
| --- | --- |
| 在项目 A 提交“这次想住海边”，等待整理完成 | 有读取权限的第二个客户端能召回海边偏好，并查看允许引用的来源。 |
| 补充“改主意了，想住湖边” | 当前偏好更新为湖边，回顾原计划时仍能区分先后。 |
| 在独立样例中更正“刚才说错了，是湖边” | 回答当前偏好时使用湖边，历史记录能说明海边是一次口误。 |
| 使用只授权项目 B 的连接读取项目 A | 读取结果不会包含项目 A 的私有事实。 |
| 在控制台删除该记忆，再从客户端查询 | 该记忆停止出现在召回结果中。 |

操作与参数见[客户端接入协议](客户端接入协议.md)。
